## INVESTOR Q&A — TOP QUESTIONS

### Q: "How is PropPulse data acquired?"
A: "Public web sources via AI agents. Today's stack: Claude Sonnet 4.5 + Anthropic web_search tool. The agents scan developer websites, news, public announcements. Each finding is confidence-scored and queued for human verification. **Phase 2** adds paid sources — RERA Dubai, DLD project registry, premium data feeds — which dramatically expand coverage. Today we're at Tier 1. Your capital funds Tier 2."

### Q: "What stops competitors from copying?"
A: "Three barriers compounding. **One** — the architecture (Intelligence + Compliance + Workflow integrated, not bolted together). **Two** — the verified data (every brokerage we onboard contributes verification signal that no competitor's data ever sees). **Three** — the verification flywheel (we have a process and tooling for confident AI + human collaboration that took months to build). By month 18, our intelligence layer is structurally uncatchable."

### Q: "What if Claude/Anthropic changes pricing or API?"
A: "Three protections. We're vendor-portable — the AI agent logic is in our code, not Anthropic's. We could switch to OpenAI or open models with minor refactor. We're cost-controlled — soft caps per call, total budget < AED 100/day at current scale. And we own the verification queue, so even if AI quality dropped, our human-verified data persists."

### Q: "Why UAE specifically?"
A: "Three reasons. **Unique compliance** — UAE has specific structures (DLD fees, off-plan vs ready, master agreements) generic CRMs don't model. **High commission deals** — brokers earn 2-4% on AED 2-10M deals, can pay for software protecting their license. **Springboard market** — successful UAE = strong launch into Saudi (Vision 2030 buildout) and broader GCC."

### Q: "Tech stack — defensible?"
A: "Pragmatic. React + Supabase (Postgres) for the app. Anthropic API for AI. Vercel for deployment. We move fast. Phase 2 we'd add specialized services for PDF generation, OCR, paid data ingestion. Architecture is multi-tenant from day one — RLS on every table, company_id-scoped queries."

### Q: "Multi-tenant security?"
A: "Row-Level Security on every table. Each brokerage isolated by company_id, enforced server-side. We can run penetration tests with your team before pilot expansion. PropPulse data is intentionally cross-tenant — it's the shared intelligence layer benefiting every broker."

### Q: "Revenue model?"
A: "SaaS per-agent per-month. Tiered: Basic (workflow), Pro (workflow + Coach), Enterprise (workflow + Coach + custom integrations). ~AED 200-400/agent/month. PropPulse intelligence layer monetizable as separate subscription. Future marketplace commissions on developer-side integrations."

### Q: "Path to profitability?"
A: "First 10 brokerages = product-market fit. 50 brokerages = positive unit economics. 200+ brokerages = strong margin. UAE alone has 800+ active brokerages — significant headroom before regional expansion."

### Q: "What's pre-MVP?"
A: "Three areas being polished. **PDF generation** for broker proposals (designed, Phase 2 — currently inline). **AI brochure scanner** (existing infrastructure, needs re-enablement). **Multi-tenant feature parity** for some screens. None of these blocks core demo or pilot. All on a 60-day roadmap."

### Q: "Why now?"
A: "Three converging factors. **AI cost curve** — Claude API costs collapsed 10x in 12 months, making PropPulse economically viable for first time. **UAE real estate boom** — Vision 2030 + Expo + Golden Visas driving multi-year tailwind. **Broker pain point compounding** — more developers per broker = more portals = more pain. Now is exactly the right moment."
